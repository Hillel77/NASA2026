# TerraNova

Ranks every land cell on Earth by how well it reproduces selected lunar or Martian conditions,
using NASA POWER, AWS Terrain Tiles, ESA WorldCover and Natural Earth data.

Source code and full documentation: see the GitHub repository's README.
